# Folder nota pelajaran / Lesson notes folder

Letak fail nota pelajaran di sini (`.md` atau `.txt`). Cikgu PAHAM akan mencari dalam nota ini dan menggunakannya sebagai konteks semasa menjawab.

Put lesson notes here as `.md` or `.txt` files. Cikgu PAHAM searches them and uses them as context when answering.

- No restart is needed: files are re-read automatically when they change.
- Separate topics with blank lines; long notes are split into passages.
- This README itself is ignored.

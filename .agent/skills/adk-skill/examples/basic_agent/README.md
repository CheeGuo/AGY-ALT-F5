# Basic ADK Agent Example

A starter agent showing function tool definitions, docstring parameter parsing, and single-agent execution.

## Testing Locally

1. Create a virtual environment and install ADK:
   ```bash
   pip install google-adk
   ```

2. Set your Gemini API key:
   ```bash
   export GOOGLE_API_KEY="your-api-key"
   ```

3. Run in the CLI:
   ```bash
   adk run basic_agent
   ```

4. Or open the web UI:
   ```bash
   adk web --port 8000
   ```
